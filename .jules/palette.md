## 2024-05-24 - [GestureDetectors on Clickable Icons]
**Learning:** Found a pattern of using `GestureDetector` wrapped around `Icon` and `Container` widgets for interactive elements throughout the app's components (e.g., tasks list, reminder banner, AI beacon). While functional for sighted users, this pattern is completely opaque to screen readers because it provides no semantic meaning, and fails to offer necessary UX feedback like visual ripples and proper keyboard focus states.
**Action:** Consistently replace `GestureDetector` used for simple interactions with standard interactive widgets like `IconButton` (which inherently supports `tooltip` and ripples), or `InkWell` wrapped inside a `Semantics` widget. Use `constraints: const BoxConstraints()` and zero padding on `IconButton` when tight packing is needed in dense layouts.
