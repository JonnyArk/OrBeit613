## 2026-09-05 - Dynamic Accessibility Semantics for Interactive Elements
**Learning:** In Flutter, AI interface components that change visual state must dynamically update their Semantics properties (such as label) based on the component's state to maintain proper accessibility context for screen readers. Also, when defining a hint for a Semantics widget, avoid hardcoding interaction instructions like 'Double tap to', since screen readers automatically provide appropriate interaction verbs based on the widget's supported actions.
**Action:** When implementing interactive elements with dynamic visual states (like voice beacons or loading indicators), wrap the interactive area in a Semantics widget and compute the label and other semantic properties dynamically within the build method, omitting redundant hint instructions for button semantics.
