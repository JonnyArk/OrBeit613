## 2024-05-19 - Replacing `GestureDetector` with `IconButton` for Interactive Icons
**Learning:** While `GestureDetector` offers granular control over touch events, it lacks essential accessibility semantics (like ARIA roles or tooltips) and native visual feedback (like ripple effects). In a complex layout like `TaskListPanel`, replacing it with `IconButton` immediately improves accessibility and UX, but it can disrupt the tight layout because `IconButton` enforces a minimum touch target size (48x48) by default.
**Action:** When converting custom `GestureDetector` icons to accessible `IconButton` elements within tight constraints, always apply `constraints: const BoxConstraints()` to the `IconButton`. This forces it to adopt the size defined by its internal `padding` and `icon` size, preventing unintended layout shifts while still providing the required accessibility label (`tooltip`) and visual feedback.
