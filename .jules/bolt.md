## 2024-11-05 - Optimize ListView.builder in LifeEventTimeline
**Learning:** In Flutter, when using `ListView.builder` to optimize heterogeneous lists (e.g., mixing headers and task items), flatten the underlying data models into a single linear list (e.g., `List<Object>`). Avoid caching it in a parallel mutable state variable. Instead, use memoized providers or derive it outside the widget state. Alternatively, if flattening synchronously inside `build()`, map the data into a list of lightweight closures (e.g., `List<Widget Function()>`) to be called by `itemBuilder`, preserving lazy evaluation without eagerly instantiating the widgets.
**Action:** I will map the events and date headers into a list of builder functions inside `_buildTimeline` before passing it to `ListView.builder`. This avoids returning a nested `Column` for every item in the `ListView.builder`, improving scrolling performance, layout speed, and ensuring correct lazy loading.
