## 2024-05-24 - Uncapped Staggered Animations Cause Initial Render Spikes
**Learning:** In Flutter, applying a staggered animation delay based purely on the `index` (e.g., `index * 50ms`) inside a `ListView.builder` or a `ListView` with many children can cause a performance issue. If the list is large, the items further down get scheduled with massive delays. Even worse, if it's not virtualized properly or if the user scrolls quickly, the framework has to calculate and schedule all these animations. Capping the delay prevents this performance degradation while maintaining the visual effect for the initial visible items.
**Action:** When using staggered animations (`delay: Duration(milliseconds: index * X)`) in a list, always cap the multiplier (e.g., `index < 10 ? index * X : 0`) so that off-screen or later items don't accumulate unnecessary delay computations and delays.
