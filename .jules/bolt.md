## 2024-05-24 - Virtualize Heterogeneous Flutter Lists
**Learning:** Virtualizing grouped data sets (like Priority tasks with headers) in Flutter by replacing `ListView` with `CustomScrollView` + `SliverChildBuilderDelegate` prevents significant O(N) memory bloat and UI locking. However, combining virtualization with `flutter_animate` delays causes erratic layout skips because off-screen items wait to render as they are scrolled into view.
**Action:** When migrating an eager list to `SliverChildBuilderDelegate`, flatten grouped structures into a single `_ListItem` array with an explicit enum type. Also, ensure you remove index/modulo-based `delay:` configurations from `flutter_animate` calls on the list items so they immediately render when instantiated by the sliver builder.
