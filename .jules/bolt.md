## 2024-08-31 - Flutter ListView Eager Mapping Anti-Pattern
**Learning:** In Flutter, eagerly building lists of widgets to be passed into a `ListView` (or directly mapping a data structure to widgets inside `ListView.children`) nullifies the performance benefits of lazy loading, leading to O(N) widget building when the list is rendered. `app/lib/ui/task_list_panel.dart` and `app/lib/ui/life_event_timeline.dart` are both using O(N) up-front calculations rather than relying strictly on the `itemBuilder` in a `ListView.builder`.
**Action:** Always map varied data models (like headers, items, completed items) into a flat list of simple Dart records or classes BEFORE handing them to `ListView.builder`. Only do the actual widget construction (instantiation) inside the `itemBuilder` callback so that Flutter lazily creates and bounds the rendering for visible items only. Also, when adding delay to animations, ensure the delay multiplier is capped so lazily built widgets don't stall appearing.
