## 2026-08-30 - ListView.builder Lazy Loading & Animation Delays
**Learning:** When refactoring an eagerly built Flutter `ListView` to a lazy-loaded `ListView.builder`, unbounded index-based animation delays (e.g., `delay: Duration(milliseconds: i * 40)`) will cause lazily-loaded items further down the list to stay invisible for several seconds upon scrolling. Also, attempting to eagerly build an array of closures (e.g., `List<Widget Function()>`) is an anti-pattern that sacrifices performance and readability.
**Action:** Always cap the index multiplier (e.g., `(i > 10 ? 10 : i) * 40`) to preserve a smooth scrolling experience. Map the data model into a flat list of items using Dart 3 records (e.g., `({String type, dynamic data, int index})`) and dynamically evaluate them inside the `itemBuilder` callback.
