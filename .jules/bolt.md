## YYYY-MM-DD - Refactoring ListView to ListView.builder in Flutter
**Learning:** In Flutter, passing pre-instantiated widgets into `ListView` or `ListView.builder` negates its lazy-loading performance benefits. Furthermore, when refactoring an eagerly-instantiated list (e.g., `ListView` with a `children` array) to use lazy loading (e.g., `ListView.builder`), index-based staggered entrance animations on the list items (e.g., `delay: Duration(milliseconds: i * 40)`) must be removed or adjusted. If left in, items scrolling into view will inappropriately trigger entrance delays, causing visual regressions and scroll jank.
**Action:** Flatten heterogeneous data into lightweight data structures (e.g., an array of maps) and dynamically instantiate the widgets inside the `itemBuilder` callback based on the item type. Remove stagger delays to prevent scroll jank.
