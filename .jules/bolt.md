## 2024-06-25 - Flutter ListView.builder lazy loading & staggered animation delays
**Learning:** In Flutter, passing pre-instantiated widgets into `ListView.builder` negates its lazy-loading performance benefits. To optimize heterogeneous lists while maintaining strong typing and preserving local variables (like index for staggered animations), construct an array of closures (e.g., `List<Widget Function()>`) and evaluate them dynamically inside the `itemBuilder` callback, instead of using weakly-typed Maps or dynamic objects. Additionally, applying staggered index-based animation delays (e.g., `delay: i * 40ms`) inside a lazy-loaded `ListView.builder` causes off-screen items to have massive delays when they are scrolled into view.
**Action:** When migrating such lists, use an array of closures for heterogeneous children and cap the delay (e.g., `math.min(i, 10) * 40`) so that initial items stagger correctly but items scrolled into view appear immediately.
