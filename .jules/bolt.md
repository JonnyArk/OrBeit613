## 2026-08-22 - Virtualizing heterogeneous lists with `ListView.builder`
**Learning:** In Flutter, eagerly building an array of widgets or closures for a `ListView` can cause O(N) upfront allocations and degrade performance. To lazily render a heterogeneous list (e.g. headers, items, spacers), the data model must be flattened into a single list of primitives or models so that `ListView.builder` can dynamically evaluate them via `itemBuilder`. Additionally, when using staggered animations on lazily-loaded items, unbounded index-based delays will make off-screen items invisible for seconds upon scrolling.
**Action:** Always map heterogeneous list data to a flat `List<Map>` or equivalent and cap animation delays (e.g., `(index > 10 ? 10 : index)`) when converting to `ListView.builder`.
