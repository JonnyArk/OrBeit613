
## 2024-05-24 - Virtualizing Heterogeneous Flutter Lists
**Learning:** Eager instantiation of Widgets within a standard `ListView` using collection-for loops causes memory bloat and potential rendering stutters for large lists. Furthermore, trying to virtualize a multi-section grouped list (with headers and items, plus conditional bottom sections) directly into `ListView.builder` can be complicated by the index-to-item mapping. Also, animating items inside a dynamically built list using staggered delays based on index (e.g., `i * 40.ms`) causes issues because lazily loaded items will delay arbitrarily when scrolled into view.
**Action:** When virtualizing heterogeneous grouped lists, explicitly flatten the grouped structure into a single array of wrapped typed objects (e.g., `_TaskListItem`) with an explicit `enum` type. This allows `ListView.builder` to dynamically render the correct widget per index cleanly. Remove index-based animation delays for lazily loaded items; they should animate immediately (`duration` only) upon entering the viewport.
