## 2025-02-09 - Optimize ListView rendering with lazy evaluation
**Learning:** In Flutter, passing pre-instantiated widgets into ListView.builder negates its lazy-loading performance benefits. To correctly optimize heterogeneous lists, flatten the data into lightweight data structures (e.g., an array of maps) and dynamically instantiate the widgets inside the itemBuilder callback based on the item type. When refactoring an eagerly-instantiated list to use lazy loading, you must remove or adjust index-based staggered entrance animations on the list items, otherwise items scrolling into view will inappropriately trigger entrance delays, causing scroll jank.
**Action:** Use an array of maps and dynamic casting inside itemBuilder when rendering heterogeneous list views. Remove fixed animation delays.
