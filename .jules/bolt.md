## 2024-03-18 - ListView.builder for Virtualizing Heterogeneous Lists
**Learning:** Eagerly evaluating large nested or grouped lists using `ListView(children: [...])` degrades rendering performance. Furthermore, using index-based arbitrary animation delays inside virtualized, lazily-loaded lists (like `ListView.builder`) causes unexpected UI waits when items are eventually scrolled into view later.
**Action:** When refactoring dynamic Flutter Map groupings (e.g., grouping models by priority enum) to optimize performance, flatten the grouped data structure into a single array of wrapped objects with an explicit type enum (e.g., `_TaskListItemType`). This allows passing the single array to `ListView.builder` to enable true lazy loading, dynamically rendering the correct widget per index. Remove any index-based animation delays so items animate immediately upon scrolling into view.
