## YYYY-MM-DD - Optimize ListView to ListView.builder for Lazy Loading
**Learning:** In Flutter, passing pre-instantiated widgets into `ListView.builder` negates its lazy-loading performance benefits. To correctly optimize heterogeneous lists, flatten the data into lightweight data structures (e.g., an array of maps) and dynamically instantiate the widgets inside the `itemBuilder` callback based on the item type. When refactoring an eagerly-instantiated list (e.g., `ListView` with a `children` array) to use lazy loading (e.g., `ListView.builder`), you must remove or adjust index-based staggered entrance animations on the list items (e.g., `delay: Duration(milliseconds: i * 40)`). If left in, items scrolling into view will inappropriately trigger entrance delays, causing visual regressions and scroll jank.
**Action:** Always flatten data structures when using ListView.builder for heterogeneous lists and remove staggered entry animations that break when lazy-loading.
