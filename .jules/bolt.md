## 2026-07-06 - Optimizing heterogeneous lists in Flutter with ListView.builder
**Learning:** In Flutter, passing pre-instantiated widgets into ListView.builder (or using an eagerly-instantiated ListView with a large array of children) negates its lazy-loading performance benefits. Also, when refactoring an eagerly-instantiated list to use lazy loading, index-based staggered entrance animations on the list items (e.g., delay: Duration(milliseconds: i * 40)) must be removed to prevent items scrolling into view from inappropriately triggering entrance delays, causing visual regressions and scroll jank.
**Action:** To correctly optimize heterogeneous lists, flatten the data into lightweight data structures (e.g., an array of maps) and dynamically instantiate the widgets inside the itemBuilder callback based on the item type. Ensure any index-based animation delays are removed from dynamically loaded items.
