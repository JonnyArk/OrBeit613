## 2025-02-05 - Lazy List Anti-Patterns: Index-Based Animation Stagger
**Learning:** In a lazy list (like Flutter's `ListView.builder`), using an absolute item index to calculate an animation stagger delay (e.g., `delay: Duration(milliseconds: index * 50)`) completely breaks the perceived performance of the app. Because items further down the list are built with increasingly massive delays, users scrolling down will experience empty screens for several seconds before the UI "catches up" and fades in. Additionally, flattening heterogeneous lists for "true virtualization" should never be done synchronously inside the `build()` method, as it converts an O(1) render into an O(N) main-thread bottleneck, nor should the flattened result be cached in a parallel mutable state variable which introduces severe synchronization bugs.
**Action:** Always remove absolute index-based delays from animations within lazily loaded list items to prevent massive delays when elements are finally scrolled into view. When attempting to flatten data for `ListView.builder` optimization, ensure the flattened structure is derived outside the widget's local state (e.g., via a memoized provider) to prevent O(N) rendering loops and state de-synchronization.
