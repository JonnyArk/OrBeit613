## 2024-05-18 - Eager List Views and Animations in Flutter
**Learning:** Using `ListView(...)` without the `builder` eagerly instantiates all children items, creating an O(N) widget building bottleneck for long lists. Furthermore, adding index-based delays to animations within a lazily loaded list (like `.fadeIn(delay: i * 40.ms)`) introduces arbitrary UI waits when items are scrolled into view, degrading perceived performance.
**Action:** Always prefer `ListView.builder` for unbounded or potentially long lists. To implement heterogeneous items (like headers, tasks, and completed tasks), flatten the groups into a single explicit array of wrapped objects before feeding it to the builder. Finally, remove index-based delays on items; animate them immediately using only `duration` when they appear on screen.
