## 2024-05-24 - Optimize ListView performance with lazy loading
**Learning:** Eagerly-instantiated lists (e.g. ListView with a children array) load all items at once, which causes memory overhead and scroll jank for heterogeneous data. Passing pre-instantiated widgets into ListView.builder negates its lazy-loading performance benefits. Furthermore, unidiomatic use of Map<String, dynamic> Abandons type safety. Using Dart 3 records (e.g., List<({String type, dynamic payload})>) or sealed classes is the proper way. Item-level animations with `flutter_animate` need to be removed as they trigger on every build when scrolled into view.
**Action:** Flatten the heterogeneous data into typed records, dynamically instantiate widgets inside itemBuilder, and remove item-level staggered entrance animations.
