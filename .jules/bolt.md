## 2026-04-03 - Optimize Virtualized List Rendering and Animations
**Learning:** Eagerly rendering grouped lists with `ListView` and `children: [...]` pre-instantiates all Widgets, creating memory overhead and performance bottlenecks for long lists. Also, using `index`-based animation delays inside `ListView.builder` causes arbitrary UI waits for items scrolled into view later, because the index continues to increment.
**Action:** Replace eager `ListView` with `ListView.builder` for virtualization. When dealing with heterogeneous lists, flatten the data structure into a single array of wrapped objects with an explicit type enum to allow the builder to dynamically render the correct widget per index. Remove index-based animation delays for items in virtualized lists; items scrolled into view should animate immediately using only `duration`.
