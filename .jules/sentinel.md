## 2026-02-05 - Fix Unauthenticated AI Endpoints and IDOR Vulnerability
**Vulnerability:** Publicly exposed HTTP endpoints (`generateAsset`, `distillContext`, `creditUsage`) lacked authentication and authorization checks, allowing anyone to execute AI business logic and potentially pass arbitrary `userId` values to spoof actions under another user's identity (IDOR/spoofing).
**Learning:** The endpoints were exposed as standard HTTP functions (`onRequest`) without manual validation of `Authorization` headers. While client applications expected to send authorization, the server did not verify it, trusting the client payload completely.
**Prevention:** Always implement `getAuth().verifyIdToken()` on sensitive `onRequest` endpoints to validate the Bearer token. To prevent IDOR vulnerabilities, securely extract the `uid` from the verified token and enforce it as the ultimate truth for user identity by injecting it directly into request payloads, overriding any user-supplied IDs.
