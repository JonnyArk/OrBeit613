## 2025-02-12 - Missing Authentication on Cloud Functions
**Vulnerability:** The Firebase Cloud Functions (`creditUsage`, `generateAsset`, `distillContext`) were exposed without requiring any authentication checks, allowing unauthenticated users to invoke them, consume AI resources, and potentially cause denial of service or unexpected credit usage.
**Learning:** These endpoints are accessed by browser clients (Flutter Web/Mobile), meaning manual authentication checks (e.g., verifying a Bearer token via `getAuth().verifyIdToken()`) need to be performed. Firebase `onRequest` endpoints do not inherently protect themselves from unauthenticated invocations. Additionally, manual authentication checks must be placed inside the callback of a CORS middleware wrapper (e.g., `cors({ origin: true })`). Placing the auth validation outside the wrapper blocks `OPTIONS` preflight requests, causing CORS failures on the client.
**Prevention:** Always ensure `onRequest` Cloud Functions accessed by client applications have explicit authentication checks by validating tokens (e.g., via a wrapper). Also, always handle CORS *before* applying authentication logic to ensure preflight checks succeed.
