## 2025-02-14 - Add authentication to external Firebase Functions
**Vulnerability:** Found unauthenticated Cloud Functions exposed via the `onRequest` trigger (`generateAsset` and `distillContext`). Since these functions don't check `context.auth` or tokens (which `onCall` handles automatically), any external user could directly call them and potentially run up Google AI ultra API costs.
**Learning:** When creating standard `onRequest` HTTP functions that act as APIs for browsers or external clients, we must manually verify Firebase Auth tokens via `admin.auth().verifyIdToken()`. Additionally, we need to wrap the endpoint logic in a CORS handler so that OPTIONS preflight requests aren't blocked by the 401 response.
**Prevention:** Always implement an authentication check like `requireAuth` inside a CORS callback for sensitive `onRequest` HTTP endpoints, or consider using Firebase `onCall` functions which automatically handle Auth and CORS if the client is using the Firebase SDK.
