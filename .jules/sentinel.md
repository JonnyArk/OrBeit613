## 2024-05-24 - Missing Authentication on Sensitive Endpoints
**Vulnerability:** Found that Cloud Function endpoints like `generateAsset` and `distillContext` lacked user authentication verification. They allowed any client to consume AI credits or access services without providing valid Firebase ID tokens. The `userId` in `AssetGenerationRequest` or `DistillationRequest` was just taken from the request body without validation, leading to potential spoofing and IDOR (Insecure Direct Object Reference).
**Learning:** In Firebase Cloud Functions using `onRequest`, the `request.auth` property is not automatically populated like it is in `onCall` functions. Authentication must be manually verified using `getAuth().verifyIdToken()`. Relying on client-provided `userId` in the payload without verification allows users to impersonate others and consume their resources or system resources.
**Prevention:** Always verify the Authorization header using Firebase Admin Auth for `onRequest` functions. Never trust client-provided `userId` in the payload; instead, securely inject the authenticated `uid` derived from the verified token. Create an authentication middleware or helper function to standardize this verification across all HTTP endpoints.
