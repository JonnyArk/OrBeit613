## 2024-05-18 - [Fix missing authentication and IDOR in AI endpoints]
**Vulnerability:** The AI endpoints `creditUsage`, `generateAsset`, and `distillContext` were exposed without proper authentication, and the AI Service business logic allowed clients to spoof user IDs, leading to potential IDOR (Insecure Direct Object Reference) vulnerabilities. Sensitive business metrics were also leaked in the `healthCheck` endpoint.
**Learning:** This occurred because backend AI services exposed as standard HTTP endpoints (`onRequest`) did not have built-in Firebase Authentication checks like `onCall` endpoints. Thus, the client payload could dictate the user identity without validation.
**Prevention:** Always secure `onRequest` HTTP endpoints using manual authorization header verification (`getAuth().verifyIdToken()`) and overwrite client-supplied identity fields (`body.userId`) with the verified `uid` derived from the token to prevent IDOR/spoofing vulnerabilities. Also, exclude sensitive metrics from public health checks.
