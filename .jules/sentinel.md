## 2024-05-18 - [CRITICAL] Fix unauthenticated endpoints and IDOR
**Vulnerability:** Found unauthenticated access to AI endpoints (`generateAsset`, `distillContext`, `creditUsage`) exposed via `onRequest`. Also, the `healthCheck` endpoint was exposing sensitive credit usage data publicly. The `generateAsset` and `distillContext` endpoints were also vulnerable to IDOR because they trusted `userId` from the unverified request body, which could allow spoofing and abuse of another user's quotas.
**Learning:** `onRequest` functions are fully public by default unlike `onCall` functions which automatically handle `request.auth`. Using `onRequest` requires explicit authentication implementations like extracting the `Authorization` header and validating it with `getAuth().verifyIdToken()`.
**Prevention:** For `onRequest` endpoints that need a user identity, explicitly extract and verify a Bearer token in the `Authorization` header. To prevent IDOR vulnerabilities, never trust `userId` or similar identifiers provided in the client request body; overwrite them with the securely retrieved `uid` from the verified auth token.
