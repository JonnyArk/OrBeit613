## 2025-04-25 - Missing Authentication on Sensitive Endpoints
**Vulnerability:** Found `creditUsage`, `generateAsset`, and `distillContext` in `functions/src/index.ts` lacking authentication checks. They processed requests directly without verifying the caller, allowing unauthenticated access and potential IDOR/spoofing of `userId` when provided via client payload.
**Learning:** `onRequest` functions in Firebase v2 do not automatically enforce authentication like Callable functions do. Also, since `@types/express` is missing, `no-explicit-any` ESLint rules fail when accessing `.headers.authorization` on generic requests unless custom types are provided.
**Prevention:** Always implement an explicit authentication check (e.g., using `getAuth().verifyIdToken()`) at the top of `onRequest` endpoints. Provide custom structural types (e.g., `TypedRequest`) to safely read headers. Securely inject the verified `uid` directly into the request payload rather than trusting client-provided `userId` parameters to prevent spoofing.
