## 2024-06-18 - Missing Authentication and IDOR on HTTP Endpoints
**Vulnerability:** Public HTTP endpoints (`generateAsset`, `distillContext`, `creditUsage`) exposed via Firebase `onRequest` were completely unauthenticated. For AI generation endpoints, the `userId` was being read directly from the client's unverified JSON payload (`body.userId`), leading to a critical Insecure Direct Object Reference (IDOR) and spoofing vulnerability.
**Learning:** In Firebase Cloud Functions v2, unlike `onCall` functions which automatically handle and attach `request.auth`, standard HTTP `onRequest` functions do not automatically verify user authentication.
**Prevention:** For any `onRequest` endpoint that performs operations scoped to a specific user or consumes shared resources (like AI credits), manually extract the bearer token from the `authorization` header and verify it using `getAuth().verifyIdToken()`. Always overwrite any client-provided user identifier (e.g., `body.userId`) with the verified `uid` returned by the auth service to prevent IDOR and spoofing.
