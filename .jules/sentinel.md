## 2025-03-10 - [CRITICAL] Fix missing authentication on AI endpoints
**Vulnerability:** The AI endpoints exposed via `onRequest` (`generateAsset`, `distillContext`, and `creditUsage`) lacked authentication, allowing unauthorized users to make requests, trigger expensive AI operations, and potentially spoof user IDs by providing a `userId` in the payload. This leads to billing abuse and Insecure Direct Object Reference (IDOR) vulnerabilities.
**Learning:** `onRequest` HTTP Cloud Functions do not automatically verify Firebase Authentication tokens unlike `onCall` functions. AI Service business logic requires a secure user ID to function correctly and bill appropriately.
**Prevention:** Always extract and verify the `Authorization` header using `admin.auth().verifyIdToken()` in public `onRequest` endpoints. Furthermore, explicitly overwrite any client-provided user ID (e.g., `body.userId`) with the authenticated `uid` from the decoded token to completely eliminate spoofing risks.
