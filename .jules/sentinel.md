## 2024-10-24 - Missing Authentication on Firebase v2 HTTP Functions
**Vulnerability:** Firebase Cloud Functions v2 `onRequest` handlers lack the built-in authentication context provided by `onCall`. Sensitive endpoints for asset generation and context distillation were completely unauthenticated, allowing arbitrary users to consume AI credits and potentially access resources by passing arbitrary `userId` fields (IDOR).
**Learning:** When migrating or writing new v2 HTTP endpoints, manual token extraction and verification using `getAuth().verifyIdToken()` is strictly required. Client-provided identity claims (like `userId` in the request body) must never be trusted.
**Prevention:** Always extract and verify the Bearer token in `onRequest` endpoints. Overwrite any client-provided identity fields with the verified `uid` from the decoded token to prevent Insecure Direct Object Reference (IDOR). Consider using `onCall` instead for simpler authenticated client-server communication.
